CSS Units — When to Use px, em, rem, and Percentages

Author: Stephanie Perdomo

Explanation

Choosing the right CSS unit is essential because it affects how your layout behaves across different devices and screen sizes. Pixels (px) are fixed units that stay the same no matter the user’s settings, which makes them useful for precise UI details like icons or borders—but they are not very responsive.

Ems (em) scale based on the font size of the parent element. For example, if the parent font size is 16px, then 2em equals 32px. This is helpful when you want spacing or text to scale with its container, but nesting can make calculations tricky.

Rems (rem) also scale, but they are always based on the root HTML font size. This makes them more predictable and easier to maintain across an entire site, especially for typography and spacing systems. Percentages (%) are relative to the parent container’s size, which makes them perfect for responsive layouts that need to stretch or shrink depending on screen width.

Using the correct unit helps your design stay flexible, readable, and consistent across all devices.

Example

This simple demo shows how different units affect size and layout:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>CSS Units Demo</title>
  <style>
    body { font-size: 16px; }

    .px-box { width: 100px; height: 50px; background: lightblue; }
    .em-box { font-size: 1.5em; background: lightgreen; }
    .rem-box { font-size: 2rem; background: lightcoral; }
    .percent-box { width: 50%; background: peachpuff; }
  </style>
</head>
<body>
  <div class="px-box">100px wide</div>
  <div class="em-box">1.5em text</div>
  <div class="rem-box">2rem text</div>
  <div class="percent-box">50% width</div>
</body>
</html>

When to Use

  • px — Use for fixed, precise sizes like icons, borders, and very small UI elements.
  • em — Use when an element’s size should scale with its parent (component padding, nested text, etc.).
  • rem — Use for global typography and spacing that should stay consistent across the entire page.
  • % — Use for flexible, responsive layouts where elements adjust to the size of their container or screen.
