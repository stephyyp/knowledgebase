# Summary: 

When working with CSS, it’s important to pick the right unit because it changes how your site looks and reacts on different screens. Pixels (px) are the most straightforward unit — they’re fixed and don’t scale. That makes them great when you need exact control, like setting a border or making an icon a specific size, but they don’t adapt well on smaller screens. Ems (em) are relative to the font size of the parent element. For example, if the parent font is 16px, then 2em equals 32px. This is useful for spacing that grows with text, but it can get tricky if you have lots of nested elements since the sizes can multiply. Rems (rem) are like ems, except they’re always based on the root font size (usually the HTML element). This makes rems more predictable and consistent across your whole site—perfect for text and spacing. Finally, percentages (%) are relative to the size of the parent container, which makes them super handy for responsive layouts that need to stretch or shrink depending on screen size.

So, use px when you want something fixed, em when you want it to scale with its parent, rem for consistent scaling everywhere, and % for flexible layouts.

# Example:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>CSS Units Demo</title>
  <style>
    body { font-size: 16px; }

    .px-box { width: 100px; height: 50px; background: lightblue; }
    .em-box { font-size: 1.5em; background: lightgreen; }
    .rem-box { font-size: 2rem; background: lightcoral; }
    .percent-box { width: 50%; background: peachpuff; }
  </style>
</head>
<body>
  <div class="px-box">100px wide</div>
  <div class="em-box">1.5em text</div>
  <div class="rem-box">2rem text</div>
  <div class="percent-box">50% width</div>
</body>
</html>

# When to Use Each Unit:

  - px: Use when you need exact, fixed sizes that won’t change, like borders, icons, or small UI details.

  - em: Great when you want sizes to scale with their parent element, like padding or headings inside a container. Be careful with nested elements since sizes can multiply.

  - rem: Best for consistent sizing across the whole page. Use it for typography, spacing, or layout elements that should scale uniformly no matter where they are.

  - %: Perfect for flexible, responsive layouts. Use percentages for widths, heights, or positioning so elements adjust to different screen sizes.

Mixing these thoughtfully helps your design stay both precise and flexible.
